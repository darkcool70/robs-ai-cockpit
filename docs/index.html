Why

One agent is easy. Four is chaos.

Terminals everywhere. You miss the moment one finishes or waits for a permission. One account hits its limit while another sits idle, and nobody knows which agent changed what. The cockpit turns that into one calm dashboard.

Notifications

A pop-up the moment an agent needs you

When an agent finishes, asks for a permission or hits a limit, a pop-up shows its actual answer, how long it took and how many files changed. Reply, dictate or jump to the session without hunting for the right terminal. Optional phone push via ntfy.

Mission control · Ctrl+0

Every agent at a glance

What each agent is doing right now, its last answer, git branch and uncommitted files. Per account: 5-hour and weekly quota with a reset countdown and a warning when you'll hit the limit before the reset.

Voice · Alt+Shift+Space

Talk to your agents from any app

Hold the shortcut, speak, release. The text lands in the focused agent. Transcription runs locally with whisper.cpp, so your audio never leaves your computer.

Task board

Hand out work, review the results

Drag tasks onto agents or let auto-dispatch give them to idle ones. Finished answers land in Review, where another agent can check them. One git worktree per task keeps agents off each other's files.

Usage

Know where your tokens go

Token figures are measured from the CLIs' own local logs, not estimated: per account, model, project, day and hour, with cache hit rate and the API-equivalent value of your subscription.

And more

Loops and queues

Repeat a prompt until "ALL TESTS PASS", or queue the next one for when the agent is done.

Auto-continue

When a CLI reports a usage limit, the cockpit waits for the reset and types "continue" for you.

Night shift

Agents work through the task list overnight and leave you a report in the morning.

Review and commit

Per-file diffs with the agent that last touched each file. Commit yourself or let an agent do it.

Other CLIs too

Gemini CLI, Aider, Ollama and other terminal tools run as agents in the same grid.

Command palette

Ctrl+P for everything, including a reusable prompt template library.

Privacy

No backend. No telemetry. No stored credentials.

  • The official claude and codex binaries do the work and handle login themselves.
  • The cockpit never reads or stores passwords, OAuth tokens or cookies.
  • API-key variables are stripped from every spawned CLI, so you are never billed per token by accident.
  • All data lives in a local SQLite database. Export and wipe are one click away.
  • This website loads no fonts, scripts or trackers from third parties.

FAQ
What do I need?

Windows 11 (Windows 10 with WebView2 should work but is untested) and at least one agent CLI on your PATH: Claude Code (claude) or the OpenAI Codex CLI (codex), with a subscription or account for each provider you use.

Windows SmartScreen warns me. Is it safe?

The installer is not code-signed yet, so Windows shows "unknown publisher". Choose More info → Run anyway. The full source is on GitHub, and you can build the installer yourself with pnpm tauri build.

Does it use my API key or cost extra tokens?

No. It starts the official CLIs with your existing subscription login and removes API-key environment variables so nothing is billed per token by accident.

Mac or Linux?

Not yet. The app is built with Tauri 2, so other platforms are possible. Tell us on GitHub if you need one.

Is this made by Anthropic or OpenAI?

No. It is an independent open-source project and is not affiliated with, endorsed by or sponsored by Anthropic or OpenAI.
