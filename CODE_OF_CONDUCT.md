# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the
work. Harassment, insults, discriminatory language and publishing other people's private
information are not tolerated.

## Enforcement

Instances of unacceptable behaviour can be reported privately to the maintainer via
[a private security advisory](https://github.com/darkcool70/robs-ai-cockpit/security/advisories/new)
(mark it as a conduct report) or by contacting [@darkcool70](https://github.com/darkcool70).
All reports will be reviewed and handled confidentially. The maintainer may remove, edit or
reject comments, commits, code, issues and other contributions that do not follow this code of
conduct.
