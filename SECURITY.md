# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report them privately via GitHub:
[**Report a vulnerability**](https://github.com/darkcool70/robs-ai-cockpit/security/advisories/new)
(Security tab → *Report a vulnerability*).

Please include what you found, how to reproduce it and which version you used. You will get an
answer within a few days. Once a fix is released, the advisory is published with credit to you
(unless you prefer to stay anonymous).

## Scope

The cockpit's trust model — what it reads, stores and never does — is described in
[docs/SECURITY.md](docs/SECURITY.md). Issues in the Claude Code or Codex CLIs themselves should
be reported to Anthropic or OpenAI respectively.
